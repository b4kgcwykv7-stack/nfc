# INÍCIO RÁPIDO

1. Instale Python 3.12+.
2. Execute `pip install -r requirements.txt`.
3. Configure `ADMIN_EMAIL`, `ADMIN_PASSWORD` e `SECRET_KEY`.
4. Execute `python init_admin.py`.
5. Execute `python app.py`.
6. Abra `http://localhost:5000/login`.
7. Cadastre um cliente.
8. Copie a URL `/p/slug`.
9. Grave essa URL na NTAG213 pelo NFC Tools.
10. Teste NFC e QR Code.

Para produção, leia `MANUAL_INSTALACAO_COMPLETO.md`.
